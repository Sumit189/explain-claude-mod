How a Transformer works

Attention, live: who is each word looking at?

Head:
Attention(Q,K,V) = softmax( Q·Kᵀ / √dk ) · V

Each word makes a Query ("what am I looking for?"), a Key ("what do I contain?") and a Value ("what I'll pass on"). Query·Key = relevance score → softmax turns scores into weights summing to 1 → the word's new vector is the weighted mix of Values. Row = word asking, column = word being looked at.

1Tokenize

Text is split into sub-word pieces ("un", "believ", "able") and each piece gets an ID from a fixed vocabulary of ~50–200k entries.

2Embed + position

Each ID looks up a learned vector (thousands of numbers). Attention itself ignores order, so position info is added (sinusoids, learned vectors, or RoPE rotations).

3Attention

Every token gathers context from relevant earlier tokens — "it" pulls in meaning from "cat". Many heads run in parallel, each learning a different kind of relation, and their outputs are concatenated.

4Feed-forward

A 2-layer MLP (expand ~4×, nonlinearity, shrink back) applied to each token independently. This is where most parameters — and much stored "knowledge" — live.

5Residual + norm

Each sub-layer adds its output to its input (x + f(x)) and is normalized. This "residual stream" lets 100+ layers train stably; each layer just edits the stream.

6Predict & repeat

The last token's vector is scored against the whole vocabulary, softmax gives probabilities, one token is sampled, appended, and the whole thing runs again.

Step 6, live: sampling the next token

Context: "The cat sat on the ___"
Temperature 1.00

Probabilities = softmax(logits / T). Low T → nearly always "mat" (deterministic). High T → flatter, more surprising picks.

Training, in one paragraph

All the weight matrices (embeddings, WQ, WK, WV, MLPs, output) start random. The model reads trillions of tokens of text, and at every position predicts the next token. The error (cross-entropy loss) is back-propagated and every weight is nudged by gradient descent. Because the causal mask hides the future, one sentence gives a training signal at every word, all computed in parallel — the key advantage over RNNs, which had to process words one at a time.

Nothing in the attention patterns above is hand-coded in a real model: heads that track grammar or resolve "it → cat" emerge because they make next-token prediction better.

Original paper: "Attention Is All You Need", Vaswani et al., 2017 (encoder–decoder for translation). GPT-style models keep just the decoder stack shown here.
